Color neighbors · sqlite-vec

Vector search, entirely in your browser. Each color is a three-dimensional RGB vector stored in a vec0 table. Choose a color to find its nearest neighbors—no extension download or server needed.

Smaller L2 distance means closer RGB values; 0 is an exact match. These are normalized RGB features, not AI embeddings or a perceptual color model.
